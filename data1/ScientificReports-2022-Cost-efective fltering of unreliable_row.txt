For these models, the computing resources typical of smartphones are sufficient.

Different techniques can be used for feature selection, generally there are three principal approaches to this 
page=5 block=-1253980160 (x=128 y=526) width=388.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
task: Filter-Based methods, Wrapper-Based methods and Embedded-Based methods37. Wrapper-Based methods 
page=5 block=-1253980160 (x=116 y=535) width=400.000000 height=7.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
and Embedded-Based methods involve using some predictor in the selection process. Wrapper-Based methods 
page=5 block=-1253980160 (x=116 y=546) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
operate based on a model that is treated as a “black box” to rank the subsets of training features regarding their 
page=5 block=-1253980160 (x=116 y=556) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
predictive power. Embedded-Based methods, on the other hand, choose the best features during the learning pro-
page=5 block=-1253980160 (x=116 y=566) width=398.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
cess. Filter-Based approaches provide a ranking of all features based on a specific relevance index. As a relevance 
page=5 block=-1253980160 (x=116 y=576) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
index, e.g. correlation coefficients can be used (i.e. Pearson, Spearman, Kendall). Correlation-based approaches 
page=5 block=-1253980160 (x=116 y=586) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
assess the relevance of the features based on the degree of dependence of the target variable (in a numerical form) 
page=5 block=-1253980160 (x=116 y=596) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
on the feature values. Different statistics can be used here, e.g. classical test statistics (Chi-squared, T-test, etc.). 
page=5 block=-1253980160 (x=116 y=606) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
Generally Filer-Based methods do not use any predictor performance optimization to select relevant features.

page=5 block=-1253980160 (x=116 y=636) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4

page=5 block=-1253980160 (x=116 y=666) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4

Conclusions
page=14 block=557844231 (x=152 y=257) width=56.000000 height=7.000000 fontname=JXWZXW+Corbel-Bold wordint.min=1 wordint.max=23
In this work we have presented the solution that can be used for cost-effective proximity detection and filter-
page=14 block=-310301848 (x=152 y=268) width=398.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
ing of unreliable results. For that purpose we designed a system that utilizes BLE RSSI readings broadcasted by 
page=14 block=-310301848 (x=152 y=278) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
static points and IMU readings. As none of the benchmark datasets available online meets all of the necessary 
page=14 block=-310301848 (x=152 y=288) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
requirements (availability of static and dynamic activities, dependence of IMU readings on BLE frames arrivals, 
page=14 block=-310301848 (x=152 y=298) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
availability of raw sensory data), we gather all necessary data with a dedicated application. We use smartphones 
page=14 block=-310301848 (x=152 y=308) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
as senders and receivers of BLE frames and for gathering of sensor data (we use an embedded IMU to obtain 
page=14 block=-310301848 (x=152 y=318) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
readings from accelerometer, gyroscope and magnetometer). We have crafted three metrics that can be used 
page=14 block=-310301848 (x=152 y=328) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
for movement detection and filtering unreliable proximity detection results. We have created two base metrics: 
page=14 block=-310301848 (x=152 y=338) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
the first one based on RSSI readings (external world information) and the second one based on the predictions 
page=14 block=-310301848 (x=152 y=348) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
of created Activity Recognition Machine Learning model based on Gradient Boosted Decision Trees (internal 
page=14 block=-310301848 (x=152 y=358) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
object information). To create the efficient model, we have used one of the filter-based feature selection tech-
page=14 block=-310301848 (x=152 y=368) width=398.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
niques and tested three ML models: Decision Tree and two ensemble models: Gradient Boosted Decision Trees 
page=14 block=-310301848 (x=152 y=378) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
and Random Forest. Using the base metrics, we have created a third metric—joint metric that combines the 
page=14 block=-310301848 (x=152 y=388) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
results of these two metrics.
page=14 block=-310301848 (x=152 y=398) width=100.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
It was shown that all of the proposed metrics can be used to assess the reliability of the proximity detection. It 
page=14 block=-310301848 (x=164 y=408) width=388.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
was proven that even without using the readings from smartphone IMU we can efficiently detect the movement 
page=14 block=-310301848 (x=152 y=418) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
and filter unreliable predictions (based only on RSSI readings). On the other hand, when we incorporate analysis 
page=14 block=-310301848 (x=152 y=428) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
of readings from IMU we can get very accurate movement detection and improve accuracy of our system. This 
page=14 block=-310301848 (x=152 y=438) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
way, we rely on both: changes in RSSI (an external information) and IMU sensors (an internal information).
page=14 block=-310301848 (x=152 y=448) width=389.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
The proposed system is flexible and can be easily customized by changing the values of the parameters used. 
page=14 block=-310301848 (x=164 y=458) width=388.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
Depending on the information at hand, reliability assessment can be based on the strength of the BLE signal or 
page=14 block=-310301848 (x=152 y=468) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
the readings from the IMU (or both of them). The created metrics do not require expensive calculations, thus 
page=14 block=-310301848 (x=152 y=478) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
can be used even in nearly real-time applications. Moreover, the great majority of operations can be conducted 
page=14 block=-310301848 (x=152 y=488) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
directly on smartphones, allowing for partial distributed computing. Additionally, the metrics are easy to inter-
page=14 block=-310301848 (x=152 y=498) width=398.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
pret, even for a non-technical operators. Using smartphones (which are usually embedded with BLE and IMU 
page=14 block=-310301848 (x=152 y=508) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
modules and provide ML engines) to conduct the experiments results in potentially easy implementation, cost-
page=14 block=-310301848 (x=152 y=518) width=398.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
efficiency and deployment of the solution in real-life applications in the areas of MICE industry, museums, art 
page=14 block=-310301848 (x=152 y=528) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
galleries and even industry. On the other hand, replacing smartphones with dedicated BLE devices may further 
page=14 block=-310301848 (x=152 y=538) width=400.000000 height=6.000000 fontname=MinionPro-Regular wordint.min=2 wordint.max=4
improve accuracy of the solution (as these devices allow advanced calibration and control over sending frames).
